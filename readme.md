# OdbVue

The meta framework for Oracle Database and VueJs

## Getting started

### Prerequisites
- [Node.js 22+](https://nodejs.org/)

### Setup

```bash
# Step 1: Clone repository
git clone <repo>
cd odbvue

# Step 2: Install dependencies
pnpm install

# Step 3: Run setup
ov setup
```
