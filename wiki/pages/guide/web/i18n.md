# Internationalization

OdbVue applications use Vue I18n. Keep shared messages in `src/i18n` and page-local messages beside their page. Messages are discovered from:

- `src/i18n/**` for application-wide translations.
- `src/pages/**/i18n/**` for page-local translations.

```text
src/
  i18n/
    en.json
    fr.json
  pages/
    sandbox/
      i18n/
        en.json
        fr.json
      index.vue
```

Use translations in pages and components with `useI18n()`.

```vue
<script setup lang="ts">
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('customers.title') }}</h1>
</template>
```

The Vue I18n and build-plugin setup is framework runtime behavior. Applications own messages and locale-specific business copy, not plugin installation.
