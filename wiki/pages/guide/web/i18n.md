# Internationalization

OdbVue applications use Vue I18n. Keep main-application messages in `src/app/i18n`, module messages in their module, and page-local messages beside their page. JSON catalogs are discovered from:

- `src/app/i18n/**/*.json` for application-wide translations.
- `src/app/pages/**/i18n/**/*.json` for main-page translations.
- `src/modules/*/i18n/**/*.json` for module translations.
- `src/modules/*/pages/**/i18n/**/*.json` for module-page translations.

```text
src/
  app/
    i18n/
      en.json
      fr.json
  modules/
    sandbox/
      i18n/
        en.json
        fr.json
      pages/
        index.vue
```

Use translations in pages and components with `useI18n()`.

```vue
<script setup lang="ts">
const { t } = useI18n()
</script>

<template>
  <h1>{{ t('customers.title') }}</h1>
</template>
```

Localization initialization lives in `src/capabilities/i18n`; application messages
live in `src/app/i18n`. The Node-only discovery, inventory, and
missing-key collector live in `plugins/i18n.ts`. The development collector writes
to the matching application/module/page scope and is disabled in production and tests.

The plugin's `appLocalesDir` option defaults to `i18n` for application-wide
messages. `i18nDir` defaults to `i18n` for page-local messages. Module-level
catalogs retain their `i18n` folders.
