# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the main repo](https://github.com/changesets/changesets).

**You probably don't need to worry about changing anything in this folder.**

The `config.json` file in this folder contains the settings for changesets in this project.
